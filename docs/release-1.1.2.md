# SoundCurrent Studio 1.1.2

- Post gain, balance and the overall output meter remain visible below every tab without scrolling.
- The peak readout retains the EQ wording, colors and localized number formats, with reserved space that prevents changing values or clipping warnings from resizing the controls.
- The reserved text area adapts to font changes while keeping normal/clipping geometry stable.
- Audio processing, gain ranges and meter refresh intervals are unchanged.

Install over the existing application; Quit Studio first. Closing its window may leave processing running. Presets and settings are retained. Only one equalizer should process audio at a time.

Windows and Linux are the supported platforms. The owner's personal review remains active; installer availability and passing CI do not establish completed production acceptance. The Windows application/installer remains unsigned, with the existing interim VB-CABLE route and setup guidance.
