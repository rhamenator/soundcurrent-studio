# SoundCurrent Studio 1.3.2

- Make the **Live** and **Offline** selector govern the **Apply settings** action: Apply is hidden and disabled during live editing, and appears enabled while an offline setup is staged.
- Increase the Live, Offline, and Apply button sizes and padding so translated labels have more breathing room.
- Add UI regression coverage for both mode states and minimum button dimensions, including right-to-left and expanded pseudo-locales.

## Upgrade

Use **Quit**, then install 1.3.2 over the existing application. Settings and custom profiles are retained. This patch does not change audio processing, drivers, equipment profiles, or SoundCurrent EQ.
