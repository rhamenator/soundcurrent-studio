# SoundCurrent Studio 1.3.5

- Put application-wide open, save, save-all, undo, reset, and Quit commands in an always-visible header, with standard keyboard shortcuts.
- Keep Automatic EQ headroom visible on every page and show Bypass Studio processing wherever it applies.
- Improve the Studio setup layout, selected-band controls, application mixer, routing controls, and scaling on smaller or high-DPI displays.
- Keep the selected spectrogram advancing through silence while reducing visualization refresh pressure on audio processing.
- Improve analyzer history bounds and display batching while retaining microphone-response accumulation accuracy.
- Expand automated UI coverage for responsive layouts, header visibility, band-count changes, silent analysis, and all localization catalogs.

## Upgrade

Use **Quit**, then install 1.3.5 over the existing application. Settings, setups, and custom profiles are retained. The public Windows package continues to use the interim VB-CABLE route; the unsigned native-driver implementation remains preserved for later production signing.
